KM Modulu Firebase Kurulumu

Okul Isleri modulunu Firebase'e kaydetmek icin iki yontem mevcuttur.

401 Hatasi aliyorsaniz: Firebase Realtime Database kurallarinizda klbk_app_permissions ve klbk_teacher_links icin yazma izni tanimli olmayabilir.

Cozum 1: Asagidaki "Kurulumu Baslat" butonunu deneyin — guncel rules dosyasi eklendi.
Cozum 2: Firebase Console sekmesini kullanin (her zaman calisir).
Kurulum Tamamlandi! enter.html'e gidin — "Degerlendirme Paneli" karti artik gorunur.

Firebase Console uzerinden asagidaki adimlari takip edin. Hicbir kod yazmadan calısır.

1Firebase Realtime Database Kurallarini Guncelle

Firebase Console → Database → Rules adresine gidin ve asagidaki kurali ekleyin:

{ "rules": { "app_store": { ".read": true, "klbk_users": { ".read": true, ".write": true }, "klbk_teacher_links": { ".read": true, ".write": true }, "klbk_app_permissions": { ".read": true, ".write": true }, "klbk_master_pin": { ".read": true, ".write": true }, "klbk_activity_log": { ".write": true }, "device_assigns": { ".read": true, ".write": true }, "klbk_zumre_plans": { ".read": true, ".write": true }, "klbk_agenda_templates": { ".read": true, ".write": true }, "active_sessions": { ".read": false, "$token": { ".write": true } }, "$storeKey": { ".write": "!data.exists() || (newData.child('_sessionToken').exists() && root.child('app_store/active_sessions/' + newData.child('_sessionToken').val()).exists())" } } } }
2teacher_links Verisini Ekle

app_store/klbk_teacher_links node'una gidin.
Mevcut veri varsa "links" dizisinin sonuna asagidaki 3 nesneyi ekleyin:

[ { "id": "km_ogretmen", "title": "Degerlendirme Paneli", "desc": "Ogrenci calisma takibi ve puanlama", "icon": "fa-chart-bar", "url": "/km2x9v3a", "active": true }, { "id": "km_admin", "title": "Calisma Yonetimi", "desc": "Calisma olustur, sinif ata, yonet", "icon": "fa-chalkboard-user", "url": "/km8b4w1e", "active": false }, { "id": "km_ogrenci", "title": "Ogrenci Calismasi", "desc": "Ogrenci giris ve calisma ekrani", "icon": "fa-graduation-cap", "url": "/km5c7r6s", "active": true } ]
3app_permissions Verisini Ekle

app_store/klbk_app_permissions node'una gidin ve asagidakileri ekleyin:

{ "km_ogretmen_html": { "globalAccess": true, "assignments": {} }, "km_admin_html": { "globalAccess": false, "assignments": {} }, "km_ogrenci_html": { "globalAccess": true, "assignments": {} } }
4Kontrol Et

Islemleri tamamladiktan sonra enter.html'e gidin. "Degerlendirme Paneli" karti artik gorUnmelidir.
master.html'den izin yonetimini yapabilirsiniz.
